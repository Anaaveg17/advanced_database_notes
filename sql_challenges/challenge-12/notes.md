## Notes
- A KPI should start with a clear business question before creating the SQL query.
- SQL functions such as COUNT(), SUM(), AVG(), CASE, and GROUP BY are essential for building business metrics.
- LEFT JOIN keeps records even when related data is missing.
- NULLIF() helps prevent division-by-zero errors.
- Productivity metrics should measure completed work, not just assigned work.
- Some KPIs can be misleading if they ignore task difficulty, priority, or workload differences.
