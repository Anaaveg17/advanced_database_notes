## What I understood
•⁠  ⁠Indexes speed up queries when you search for few rows, especially on columns with many unique values. 
Oracle may ignore indexes if too many rows match and use a full table scan instead. In composite indexes, 
column order matters, and using functions on columns can prevent index usage. 
Checking the execution plan is key to understanding performance.
