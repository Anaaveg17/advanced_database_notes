## What I understood
KPIs need clear definitions before creating SQL queries so everyone understands what is being measured and how it is calculated. I also learned that SQL functions like COUNT, SUM, AVG, and GROUP BY help turn raw data into useful business metrics. It is important to consider special cases such as missing data or cancelled tasks to keep results accurate. Different KPIs answer different business questions, and dashboards should provide context instead of only showing numbers. Finally, Python tools like pandas and Plotly can be used to visualize the data and make the results easier to understand.
